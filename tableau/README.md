# Retail Sales and Customer Performance: Tableau build notes

> **Workbook is private.** The packaged Tableau workbook and its Hyper extract are not published in this repository. The interactive dashboards will be published separately for viewing, and the screenshots in [`docs/screenshots`](../docs/screenshots) show each dashboard. This file documents the workbook structure as text.

Data source: UCI Online Retail II (a Hyper extract packaged inside the private workbook).

## Dashboards

### Sales performance

- Gross sales
- Cancellation value
- Net recorded sales
- Customer coverage
- Monthly net recorded sales
- Monthly purchase invoices
- Monthly cancellation value

### Product and market mix

- Stock codes by gross sales
- Markets by gross sales

### Customer retention

- Identified purchasers
- Repeat purchasers
- Repeat purchase rate
- Retention by months since first purchase

## Calculated fields

| Field | Formula |
| --- | --- |
| Gross sales | `SUM([gross])` |
| Cancellation value | `SUM([cancellations])` |
| Net recorded sales | `SUM([net])` |
| Customer ID coverage | `SUM([known_lines]) / SUM([purchase_lines])` |
| Purchase invoices | `SUM([orders])` |
| Stock code gross sales | `SUM([product_gross])` |
| Market gross sales | `SUM([market_gross])` |
| Identified purchasers | `SUM([purchasers])` |
| Repeat purchasers | `SUM([returning])` |
| Repeat purchase rate | `SUM([returning]) / SUM([purchasers])` |
| Cohort retention | `SUM([active]) / SUM([cohort_size])` |

## Rebuild

The workbook was generated by `build_tableau.py`. Run it locally (requires `tableauhyperapi`) to recreate the packaged workbook; it is kept out of version control.
