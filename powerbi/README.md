# Retail Sales and Customer Performance: Power BI build notes

> **Project files are private.** The Power BI project (`.pbip`, report and semantic model folders) is not published in this repository. The interactive dashboards will be published separately for viewing, and the screenshots in [`docs/screenshots`](../docs/screenshots) show each page. This folder documents the build as text: the data model, Power Query and DAX measures.

## Files in this folder

| File | Contents |
| --- | --- |
| `Model.dax` | Every DAX measure in the semantic model, grouped by table |
| `Sales.pq` | Power Query (M) for the `Sales` table |
| `Products.pq` | Power Query (M) for the `Products` table |
| `Markets.pq` | Power Query (M) for the `Markets` table |
| `Repeat.pq` | Power Query (M) for the `Repeat` table |
| `Cohorts.pq` | Power Query (M) for the `Cohorts` table |

## Report pages

### Sales performance

- KPI cards: Gross sales, Cancellation value, Net recorded sales, Customer ID coverage
- Line chart: Monthly net recorded sales
- Line chart: Monthly purchase invoices
- Line chart: Monthly cancellation value

### Product and market mix

- Bar chart: Stock codes by gross sales
- Bar chart: Markets by gross sales

### Customer retention

- KPI cards: Identified purchasers, Repeat purchasers, Repeat purchase rate
- Line chart: Retention by months since first purchase
- Slicers: First purchase cohort

## Data model

| Table | Columns | Measures |
| --- | --- | --- |
| Sales | Month, Gross, Cancellations, Net, Orders, Known Lines, Purchase Lines | 5 |
| Products | Product, Product Gross | 1 |
| Markets | Country, Market Gross | 1 |
| Repeat | Purchasers, Returning | 3 |
| Cohorts | Cohort, Elapsed Month, Cohort Size, Active | 1 |

The tables are independent. There are no relationships; each visual reads a single table.

## Rebuild

The model and report were generated by `build_powerbi.py`. Run it locally to recreate the Power BI project; the generated project files are kept out of version control.
